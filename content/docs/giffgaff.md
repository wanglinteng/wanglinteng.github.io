# Giffgaff

## What is it?
Giffgaff是英国的一家虚拟运营商，其SIM卡非常适合长期保号使用。最初，Giffgaff仅提供实体SIM卡，后来开始支持将实体卡转换为eSIM或直接购买新的eSIM。不同于其他运营商，Giffgaff不会提供eSIM二维码，而是通过Giffgaff App直接将eSIM配置文件下载到手机中。
